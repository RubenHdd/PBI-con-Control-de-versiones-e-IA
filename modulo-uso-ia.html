en Power BI.

Prepara MCP en Visual Studio Code, conecta Copilot con tu modelo semántico y comprueba que todo funciona antes de empezar el taller.

Qué vas a usar

Estas herramientas trabajan juntas para que Copilot pueda leer y ayudarte a trabajar con el modelo semántico.

Power BI DesktopAbre el informe.
VS CodeEditor donde usas Copilot.
Copilot ChatAsistente de IA.
MCPConecta Copilot con el modelo.

Instala Git y reinicia VS Code al terminar.

git --version

Instala Visual Studio Code. En Extensiones (Ctrl+Shift+X) instala GitHub Copilot Chat e inicia sesión.

En la misma vista instala Power BI Modeling MCP Server. Después abre ... en Extensiones, selecciona Views > Agent Plugins e instala powerbi-authoring.

  1. Abre Archivo > Opciones y configuración > Opciones > Funciones de vista previa.
  2. Activa guardar como proyecto de Power BI (.pbip).
  3. Guarda el informe como Proyecto de Power BI y abre su carpeta raíz desde VS Code.

Con Power BI Desktop abierto, abre Copilot Chat y pega este prompt:

Conéctate al modelo del informe que tengo abierto en Power BI Desktop, llamado «[nombre exacto del informe]». Lista las tablas, medidas y relaciones disponibles, sin modificar nada.

También puedes conectar con una carpeta PBIP indicando NombreInforme.SemanticModel\definition. Power BI Desktop sincronizará los cambios del proyecto.

Empieza con una petición de lectura y confirma que el resultado coincide con tu informe:

Resume el modelo, sin realizar cambios. Indica tablas, medidas, relaciones y el origen de datos de cada tabla.
