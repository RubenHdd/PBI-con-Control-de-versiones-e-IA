Guion del taller

De heredar un dashboard
a dominarlo con IA.

Contoso vende productos y servicios tecnológicos por distintos canales y zonas comerciales. Te incorporas a un proyecto Power BI existente y, a lo largo de este taller, aprenderás a usar IA con Power BI a través de MCP para entender el modelo, corregirlo, documentarlo y llevarlo a producción con criterio.

Antes de empezar

Vas a trabajar sobre un modelo real de Contoso. En este bloque defines cómo te conectarás con MCP y dejas lista tu vía de trabajo para que el resto de ejercicios sea fluido.

Qué es MCP MCP (Model Context Protocol) es el puente entre la IA y tu modelo semántico de Power BI. Le permite inspeccionar tablas, medidas y relaciones, proponer cambios y ayudarte a documentar más rápido.
Importante: las decisiones finales y la validación siguen siendo tuyas.

Elige una sola vía Elige solo una vía y completa su preparación antes de continuar: Vía A (VS Code) o Vía B (Copilot CLI + Skills Fabric). No mezcles rutas.

Vía A · Power BI + VS Code

  • Flujo guiado desde VS Code.
  • Ideal si ya trabajas en Power BI Desktop y quieres apoyo interactivo en el editor.

Vía B · Copilot CLI + Skills Fabric

  • Flujo completo desde terminal con MCP y skills.

⚠Pensamiento crítico, siempreLa IA acelera el trabajo, pero no sustituye tu criterio como analista. Revisa cada medida, cada relación y cada visual antes de darlos por buenos — sobre todo cuando la respuesta suene convincente. Un resultado bien redactado no es lo mismo que un resultado correcto.
