Instala, abre y verifica la conexión

Sigue los pasos de arriba abajo. Al terminar podrás pedir a Copilot que lea tu modelo Power BI y empezar los ejercicios.

Qué vas a usar

Son cuatro herramientas que trabajan juntas. No tienes que configurar nada manualmente fuera de los pasos de esta página.

Power BI DesktopLa aplicación donde abres y ves el informe.
Visual Studio CodeEl editor desde el que hablarás con Copilot.
GitHub Copilot ChatEl asistente de IA al que escribirás tus preguntas.
MCPLa conexión que permite a Copilot leer el modelo Power BI.

Git es una herramienta que necesita el complemento de Power BI. Instálalo desde su página oficial, o usa el método de instalación permitido en tu equipo. Cuando termine, cierra y vuelve a abrir VS Code.

git --version

En este paso instalarás Visual Studio Code y todo lo que se usa dentro: el chat de IA, la conexión con Power BI y la ayuda especializada para informes.

Si todavía no tienes Visual Studio Code, descárgalo desde la página oficial, instálalo y ábrelo antes de seguir.

En VS Code abre Extensiones con Ctrl+Shift+X. Busca GitHub Copilot Chat, instálalo si hace falta e inicia sesión. Al finalizar, comprueba que puedes abrir la ventana de chat de Copilot.

Instala la conexión con Power BI

Estos dos complementos se instalan dentro de VS Code. El primero conecta Copilot con Power BI; el segundo aporta ayuda especializada para crear y editar informes.

  1. En Extensiones, busca Power BI Modeling MCP Server e instálalo. Este es el servidor que da a Copilot acceso al modelo.

    Referencia visual: busca Power BI Modeling MCP Server en el Marketplace de VS Code e instálalo.

  2. En la misma vista de Extensiones selecciona ..., abre Views > Agent Plugins, usa la búsqueda e instala powerbi-authoring.

    Referencia visual: abre el menú ... de Extensiones y selecciona Views > Agent Plugins.

  3. Si VS Code solicita recargar la ventana, acepta la recarga antes de continuar.

Este formato permite que VS Code encuentre los archivos del informe y del modelo. Solo debes activarlo una vez en Power BI Desktop.

  1. En Power BI Desktop abre Archivo > Opciones y configuración > Opciones > Funciones de vista previa.
  2. Activa Opción de guardar proyecto de Power BI (.pbip). Activa también el formato PBIR mejorado si tu versión lo muestra.
  3. Selecciona Archivo > Guardar como y guarda el informe como Proyecto de Power BI (.pbip).

    Referencia visual: selecciona Proyecto de Power BI (.pbip) al guardar el informe.

  4. En VS Code usa Archivo > Abrir carpeta y selecciona la carpeta raíz que contiene el archivo .pbip, no la carpeta del informe ni la del modelo de forma aislada.

Tras guardar verás el archivo NombreInforme.pbip y dos carpetas: NombreInforme.Report contiene el informe visual y NombreInforme.SemanticModel contiene los datos, relaciones y medidas. No necesitas editar estos archivos durante el taller.

Las dos opciones permiten a Copilot trabajar sobre el mismo modelo semántico. Elige una sola: con la opción A el cambio aparece directamente en Power BI Desktop; con la opción B el cambio se escribe en los archivos PBIP y Power BI Desktop lo sincroniza periódicamente.

Opción A · Informe abierto en Desktop

Usar el informe abierto

Deja Power BI Desktop abierto con el informe correcto. Abre Copilot Chat en VS Code, selecciona Agent si aparece esa opción y pega el texto siguiente. Cuando VS Code te pida permiso, acepta el acceso de solo lectura.

Conéctate al modelo del informe que tengo abierto en Power BI Desktop, llamado «[nombre exacto del informe]». Lista las tablas, medidas y relaciones disponibles, sin modificar nada.

Opción B · Carpeta PBIP

Usar los archivos del proyecto

Conecta Copilot a los archivos del proyecto. Puedes mantener Power BI Desktop abierto: al detectar cambios en el proyecto te pedirá sincronizarlos o los sincronizará periódicamente. Si aparece un aviso de sincronización, selecciónalo antes de comprobar el resultado en el informe. Sustituye la ruta de ejemplo por la carpeta definition de tu modelo semántico.

Abre el modelo semántico de esta carpeta PBIP: C:\Ruta\NombreInforme.SemanticModel\definition. Lista las tablas, medidas y relaciones disponibles, sin modificar nada.

Antes de modificar nada, empieza con una petición de lectura. Comprueba que el nombre del informe, el número de tablas y alguna medida conocida coinciden con lo que ves en Power BI Desktop.

Resume el modelo, sin realizar cambios. Indica tablas, medidas, relaciones y el origen de datos de cada tabla.

Si algo falla

  • Si no detecta el informe, confirma que Power BI Desktop sigue abierto y vuelve a enviar el prompt con el nombre exacto.
  • Si no aparece la herramienta MCP, recarga VS Code y confirma que la extensión está habilitada.
  • Si trabajas con PBIP, asegúrate de indicar la carpeta .SemanticModel\definition, no el archivo .pbip.
  • Si la respuesta no coincide con tu modelo, detente y no apliques modificaciones.

Conexión lista

Cuando la consulta de lectura devuelva información correcta del modelo, pasa al taller. En los ejercicios que creen o modifiquen objetos, revisa el resultado en Power BI Desktop y guarda el proyecto para conservarlo.
